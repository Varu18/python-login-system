# Python Login System

A simple web-based authentication system built with Python, Flask and SQLite.

## About

This project is a learning project designed to help me understand how authentication systems work in a real web application.

The application will include:

- User registration
- User login
- Password hashing
- Session management
- Logout
- SQLite database
- Simple web interface

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- Git & GitHub

## AI Assisted

This project is AI-assisted.

I use AI as a learning tool to help me understand concepts, structure the project, debug problems and learn best practices.

I do not blindly copy code. I make sure I understand how the code works and why each part is used.

The goal of this project is to learn Python and web development by building something practical from scratch.
